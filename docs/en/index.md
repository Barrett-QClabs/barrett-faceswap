# Barrett FaceSwap

Barrett FaceSwap swaps a face in a still image, a video, or a webcam preview. The code is MIT. The InsightFace weights it can run are not, and commercial use of those weights needs a separate grant.

`compliance.enabled` stays `false` in the shipped config. Turn it on with the config or `--enable-compliance` before you use a real likeness.
