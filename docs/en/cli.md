usage: barrett-faceswap [-h] [--version] [--lang LANG]
                        {swap,jobs,live,inspect-models,list-processors,ui,benchmark,doctor,download-models}
                        ...

Face swap for a still image or a video. Compliance enforcement defaults to off for development.

positional arguments:
  {swap,jobs,live,inspect-models,list-processors,ui,benchmark,doctor,download-models}
    swap                Detect, align, swap, and paste. A video target is processed frame by
                        frame.
    jobs                Queue a swap and resume it after an interruption.
    live                Run the realtime webcam loop. Source embedding is computed once.
    inspect-models      Show model registry entries, license flags, and local file hashes.
    list-processors     List registered frame processors.
    ui                  Launch the Gradio interface.
    benchmark           Time the processor chain and print frames per second.
    doctor              Report execution providers, CUDA and cuDNN libraries, and model files.
    download-models     Download buffalo_l and inswapper_128, verify sha256, and retry mirrors.

options:
  -h, --help            show this help message and exit
  --version             show program's version number and exit
  --lang LANG           Interface language: en or zh-CN. Overrides BARRETT_FACESWAP_LANG and
                        ui.language.

options:
  -h, --help            show this help message and exit
  --source SOURCE       Source image. The face identity comes from this file.
  --target TARGET       Target image or video. The face in this file is replaced.
  --output OUTPUT       Where to write the image or video.
  --config CONFIG       Path to the YAML config. Relative paths inside it resolve from the working
                        directory.
  --dry-run             Skip ONNX inference. Useful when weights are not downloaded yet.
  --enable-compliance   Turn on consent, watermark, content filter, and audit for this run.
  --lang LANG           Interface language: en or zh-CN. Overrides BARRETT_FACESWAP_LANG and
                        ui.language.
  --consent-file CONSENT_FILE
                        JSON consent manifest for the source likeness.
  --acknowledge-authorized-use
                        State that you are authorized to use the source likeness.
  --consent-subject CONSENT_SUBJECT
                        Subject id recorded with --acknowledge-authorized-use.
  --consent-statement CONSENT_STATEMENT
                        Optional acknowledgement text. A default sentence is stored when omitted.
  --no-watermark        Skip the visible label and embedded metadata. The skip is written to the
                        audit log.
  --disable-content-filter
                        Disable the content filter. Refused unless the permission switch is set.
  --content-filter-provider {none,stub,nudenet,custom}
                        Override content_filter.provider for this run. A change requires the
                        permission switch.
  --content-filter-threshold CONTENT_FILTER_THRESHOLD
                        Override the filter score threshold.
  --no-block-on-minor   Do not block on a minor signal. Requires the permission switch.
  --processors PROCESSORS
                        Comma-separated processor names. Defaults to the config list.
  --execution-provider EXECUTION_PROVIDER
                        Execution provider to prefer. Repeat the flag to set the order. CUDA is
                        preferred when listed.
  --target-face-index TARGET_FACE_INDEX
                        Which target face to replace. 0 is the largest face.
  --trim-start TRIM_START
                        Video trim start in seconds. Requires a video target.
  --trim-end TRIM_END   Video trim end in seconds. Requires a video target.
  --video-encoder {libx264,h264_nvenc}
                        Video encoder: libx264 or h264_nvenc.
  --video-threads VIDEO_THREADS
                        How many frames to process at once.
  --no-audio            Drop the source audio instead of muxing it back.
  --filter-every FILTER_EVERY
                        When compliance is on, filter every Nth video frame. The last frame is
                        always included.
  --enhancer-model {gfpgan_1.4,codeformer}
                        Enhancer graph: gfpgan_1.4 or codeformer.
  --enhancer-blend ENHANCER_BLEND
                        Enhancer blend from 0 to 1. 1 replaces the crop with the restoration.
  --enhancer-weight ENHANCER_WEIGHT
                        CodeFormer weight from 0 to 1. Ignored when the graph has no weight input.
  --swapper-model {inswapper_128,hyperswap_1a_256,hyperswap_1b_256,hyperswap_1c_256,simswap_256,simswap_unofficial_512,ghost_1_256,ghost_2_256,ghost_3_256}
                        Swapper graph. inswapper_128 is the default. Other names need their ONNX
                        file.
  --pixel-boost PIXEL_BOOST
                        Aligned crop size. 0 uses the model native size (or swap.resolution for
                        inswapper).
  --many-faces          Replace every detected face with the source identity.
  --reference REFERENCE
                        Reference still. The target face closest to this identity is replaced.
  --face-map FACE_MAP   JSON file mapping source images to target indexes or reference stills.
  --blend-mode {alpha,poisson}
                        Paste mode: alpha or poisson.
  --color-transfer {none,mean_std,lab,histogram}
                        Color match: none, mean_std, lab, or histogram.
  --video-mode {disk,pipe}
                        Video path: disk (default) or pipe.
  --eye-mode {swap,blend,target}
                        Eye handling: swap, blend (default, keep most of the target eyes), or
                        target.
  --with-enhancer       Also run face_enhancer. Eye regions use enhancer.eye_blend.
  --job-id JOB_ID       Job id. Letters, digits, underscore, and hyphen.
  --resume              Continue a job from the last finished frame.
  --commercial          Refuse any model the registry marks commercial_use false.

usage: barrett-faceswap benchmark [-h] [--config CONFIG] [--lang LANG] [--frames FRAMES]
                                  [--width WIDTH] [--height HEIGHT] [--source SOURCE]
                                  [--target TARGET] [--dry-run]
                                  [--execution-provider EXECUTION_PROVIDER] [--live]

options:
  -h, --help            show this help message and exit
  --config CONFIG       Path to the YAML config. Relative paths inside it resolve from the working
                        directory.
  --lang LANG           Interface language: en or zh-CN. Overrides BARRETT_FACESWAP_LANG and
                        ui.language.
  --frames FRAMES       How many frames to time.
  --width WIDTH         Frame width. A still passed with --source and --target is resized to this.
  --height HEIGHT       Frame height. A still passed with --source and --target is resized to
                        this.
  --source SOURCE       Still image used as the source identity. Together with --target, the
                        benchmark detects that face instead of using the drawn fallback.
  --target TARGET       Still image repeated for --frames. Pass it with --source so detection runs
                        on a real face.
  --dry-run             Skip ONNX inference. Useful when weights are not downloaded yet.
  --execution-provider EXECUTION_PROVIDER
                        Execution provider to prefer. Repeat the flag to set the order. CUDA is
                        preferred when listed.
  --live                Time a live session and print per-stage latency. Does not open a webcam.
