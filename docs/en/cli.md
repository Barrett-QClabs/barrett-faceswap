                        {swap,jobs,live,compare,inspect-models,list-processors,ui,benchmark,doctor,download-models,library}
                        ...

Face swap for a still image or a video. Compliance enforcement defaults to off for development.

positional arguments:
  {swap,jobs,live,compare,inspect-models,list-processors,ui,benchmark,doctor,download-models,library}
    swap                Detect, align, swap, and paste. A video target is processed frame by
                        frame.
    jobs                Queue a swap and resume it after an interruption.
    live                Run the realtime webcam loop. Source embedding is computed once.
    compare             Write a labeled contact sheet and a timing table for swapper and enhancer
                        pairs.
    inspect-models      Show model registry entries, license flags, and local file hashes.
    list-processors     List registered frame processors.
    ui                  Launch the Gradio interface.
    benchmark           Time the processor chain and print frames per second.
    doctor              Report execution providers, CUDA and cuDNN libraries, and model files.
    download-models     Download buffalo_l and inswapper_128, verify sha256, and retry mirrors.
    library             Create, extend, list, and delete saved source profiles.

  -h, --help            show this help message and exit
  --version             show program's version number and exit
  --lang LANG           Interface language: en or zh-CN. Overrides BARRETT_FACESWAP_LANG and
                        ui.language.
